## 🚀 실행 방법

### 개발 서버
```bash
pnpm install
pnpm dev
```
→ http://localhost:3000

### 프로덕션 빌드
```bash
pnpm build
pnpm start
```

### Vercel 배포
```bash
vercel
```

## 📝 주요 기능

1. **입력 관리**: 원가, 가격, 믹스, COGS율, 운영 정보, 할인액
2. **자동 계산**: 기준/할인 후 GP, 필요 추가객수, 월 팀수, 객단가
3. **시나리오 비교**: 여러 할인액을 동시 비교 (표 + 차트)
4. **데이터 저장**: localStorage 자동 저장/복원
5. **입력 검증**: 믹스 합계, 마진 경고
6. **반응형 UI**: 모바일 우선, 카드 기반

## 🎯 핵심 특징

- **단일 파일 구현**: 모든 로직이 `app/pricing-sim/page.tsx` 한 파일에
- **타입 안전**: TypeScript로 모든 타입 정의
- **성능 최적화**: useMemo로 계산 캐싱
- **실시간 반영**: onChange로 즉시 계산
- **SSR 안전**: mounted 상태로 localStorage 접근
- **빌드 에러 0**: 완벽한 타입 체크

## 🔍 테스트 시나리오

### 시나리오 1: 기본 사용
1. 페이지 접속
2. 기본값으로 계산 결과 확인
3. 돼지고기 가격을 5,000원으로 변경
4. 실시간으로 GP 마진 및 필요 추가객수 확인

### 시나리오 2: 할인 시뮬레이션
1. 할인액을 500원으로 설정
2. 필요 추가객수(%) 확인
3. 시나리오 입력에 "0,500,1000,1500" 입력
4. 표와 차트로 비교 확인

### 시나리오 3: 매출 믹스 조정
1. 매출 믹스를 돼지 70%, 소 5%로 변경
2. 합계가 100%가 아니면 경고 표시 확인
3. 나머지 믹스 조정하여 합계 100% 맞추기
4. 변경된 GP 마진 확인

### 시나리오 4: 목표 설정
1. 목표 월매출을 30,000,000원으로 변경
2. 필요 객단가 자동 계산 확인
3. 현재 객단가로 달성 가능한 매출 확인
4. 할인 시 필요 팀수 확인

### 시나리오 5: 데이터 저장
1. 모든 값을 변경
2. 페이지 새로고침
3. 이전 값들이 자동 복원되는지 확인
4. "초기화" 버튼으로 기본값 복원 확인
