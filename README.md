# BION 💝

> **일상을 특별하게**  
> 기술이 아닌 사람을 위한 공간

## 🎯 프로젝트 목표

200~300개의 웹앱을 체계적으로 관리하고 제공하는 포털 사이트

## 📁 프로젝트 구조

```
bionvibe2/
├── app/
│   ├── components/
│   │   └── CategoryCard.tsx    # 카테고리 카드 (배경 이미지 포함)
│   ├── page.tsx                # 메인 페이지
│   ├── layout.tsx              # 전역 레이아웃
│   └── globals.css             # 글로벌 스타일
├── data/
│   ├── categories.json         # 카테고리 정의 (7개)
│   └── apps.json               # 모든 웹앱 데이터 (200~300개 예정)
└── lib/
    └── getApps.ts              # 데이터 로드 및 관리 함수
```

## 🗂️ 데이터 관리 시스템

### 카테고리 (7개)
1. 🍳 **음식과 일상** - 하루하루를 맛있게
2. 💚 **건강과 마음** - 나를 돌보는 시간
3. 🔮 **운세와 재미** - 오늘의 행운을 찾아서
4. 📚 **학습과 성장** - 오늘도 한 걸음
5. 💰 **돈과 생활관리** - 현명한 경제생활
6. ❤️ **가족과 사랑** - 소중한 사람들과 함께
7. 🎮 **취미와 여가** - 즐거운 시간 보내기

### 웹앱 데이터 구조

```json
{
  "id": "unique-id",
  "name": "웹앱 이름",
  "slug": "url-slug",
  "icon": "🎯",
  "description": "간단한 설명",
  "categoryId": "카테고리 ID",
  "url": "/앱경로",
  "createdAt": "2025-01-20"
}
```

## 🚀 개발 가이드

### 개발 서버 실행
```bash
npm run dev
```

### 새 웹앱 추가하기
1. `data/apps.json`에 새 앱 데이터 추가
2. 자동으로 해당 카테고리에 표시됨
3. 앱 페이지는 별도로 개발

### 로컬 개발 원칙
- ✅ 모든 데이터는 로컬 JSON 파일로 관리
- ✅ GitHub에 저장하지 않고 서버에 직접 보관
- ✅ 배포는 명시적 지시가 있을 때만 Vercel로
