# 고깃집 가격 시뮬레이터

고깃집의 가격 인하 및 회전율 전략을 실시간으로 검증하는 웹 계산기입니다.

## 기술 스택

- **프레임워크**: Next.js 14 (App Router)
- **언어**: TypeScript
- **스타일링**: TailwindCSS
- **UI 컴포넌트**: shadcn/ui
- **차트**: Recharts
- **상태 관리**: React Hooks (useState, useMemo)
- **데이터 저장**: localStorage

## 주요 기능

### 1. 입력 관리
- **원가/기본 단위**: 돼지고기/소고기 원가(원/kg), 1인분 중량(g)
- **메뉴 가격**: 돼지고기/소고기 판매가(원/인분)
- **매출 믹스**: 돼지/소/식사/음료/주류 비율 (합계 100% 검증)
- **비육류 COGS율**: 식사/음료/주류 원가율(%)
- **운영 캘린더**: 연중무휴 ON/OFF, 평일/주말 일수
- **목표 설정**: 목표 월매출, 평일/주말 팀수/일, 현재 객단가
- **할인 시나리오**: 육류 인분당 할인액, 비교 시나리오

### 2. 계산 로직
- **기준(할인 전) 계산**: 매출 10만원 단위 모델
  - 분류별 매출: 매출 × 믹스 비율
  - 육류 인분수: 매출 ÷ 인분가
  - COGS: 인분수 × 원가 (육류) / 매출 × COGS율 (비육류)
  - GP: 매출 - COGS

- **할인 후 계산**: 볼륨 동일 가정
  - 매출감소: 육류 총 인분수 × 인분당 할인액
  - 손익 동일 필요 추가객수(%): (GP기준 - GP할인후) ÷ (GPm할인후 × 매출할인후)

- **월 목표/회전 계산**
  - 월 팀수: 평일일수 × 평일팀수 + 주말일수 × 주말팀수
  - 필요 객단가: 목표 월매출 ÷ 월 팀수
  - 할인 시 손익유지 필요 팀수

### 3. 결과 표시
- **기준 요약 카드**: GP마진, COGS, 인분수
- **회전/객단가 카드**: 월 팀수, 필요 객단가, 달성 가능 매출, 할인 시 필요 팀수
- **할인 시나리오 비교**: 표 및 차트로 시각화
- **상세 분석**: 할인 전후 비교

### 4. UX 기능
- **자동 저장**: 모든 입력값 localStorage 자동 저장/복원
- **기본값 관리**: 기본값 로드/초기화 버튼
- **입력 검증**: 매출 믹스 합계 100%, GP 마진 ≤ 0 경고
- **실시간 반영**: 입력 변경 시 즉시 계산 및 결과 업데이트
- **반응형 UI**: 모바일 우선, 카드 기반 레이아웃
- **차트 토글**: 차트 표시/숨김 옵션

## 기본값

- 돼지고기 원가: 11,500원/kg
- 소고기 원가: 9,800원/kg
- 1인분 중량: 200g
- 돼지고기 판매가: 6,500원/인분
- 소고기 판매가: 8,500원/인분
- 매출 믹스: 돼지 60% / 소 10% / 식사 15% / 음료 5% / 주류 10%
- 비육류 COGS율: 식사 35% / 음료 25% / 주류 35%
- 목표 월매출: 25,000,000원
- 연중무휴: ON (30일)
- 평일 팀수/일: 14팀
- 주말 팀수/일: 24팀
- 현재 객단가: 50,000원

## 사용 방법

1. **원가 및 가격 설정**: 좌측 카드들에서 원가, 판매가, 믹스 비율 입력
2. **운영 정보 입력**: 영업일, 목표 매출, 팀수 설정
3. **할인 시나리오 설정**: 할인액 입력 (쉼표로 여러 시나리오 구분)
4. **결과 확인**: 하단 카드에서 실시간 계산 결과 확인
5. **데이터 관리**:
   - 자동 저장: 입력 시 자동으로 브라우저에 저장
   - 기본값 로드: 기본값으로 재설정
   - 초기화: 저장된 데이터 삭제 및 기본값 로드

## 주의사항

- 매출 믹스의 합계는 반드시 100%여야 합니다
- 할인액이 너무 크면 GP 마진이 음수가 될 수 있습니다
- 모든 데이터는 브라우저의 localStorage에 저장됩니다 (서버 저장 없음)
- 광고 및 추적 스크립트는 포함되어 있지 않습니다
